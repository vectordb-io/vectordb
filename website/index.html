    03 — BUILT, NOT JUST PLANNED

    Know what is ready.

    Vector search, structured data, and persistence together.
    This release focuses on a single node. Here is what is built and what is next.

    ModuleCurrent implementationStatus
    Data organization

    Databases, collections, schemas, partitions, aliases, automatic primary keys, dynamic fields

    Implemented
    Vector search

    FLAT / IVF_FLAT / HNSW; dense, sparse, and binary vectors

    Implemented
    Combined queries

    Scalar filtering, JSON paths, range search, grouping search, RRF / weighted fusion

    Implemented
    Data reliability

    Atomic batch writes, WAL persistence, restart recovery, snapshot backups

    Implemented
    Service and operations

    REST API, Bearer tokens, health checks, Prometheus counters

    Implemented
    Up next

    Distributed replication and sharding, gRPC, RBAC, BM25, GPU indexes

    Not implemented

    This is an early single-node implementation. ANN indexes are rebuilt on demand after writes; queries currently read collection data. Large-scale performance and production validation are not yet complete. SQLite is an embedded storage dependency.
