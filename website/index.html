03 / MAKE IT YOURS

从一次构建开始。

克隆仓库，安装依赖，运行测试。
这里是理解 VectorDB 的第一步。

Ubuntu 24.04.2 LTS

以下命令沿用项目 README 的构建流程。依赖安装需要 sudo，并会执行仓库的依赖脚本。

阅读构建说明↗
quickstart.sh
# 01 — Clone
git clone https://github.com/vectordb-io/vectordb.git
cd vectordb

# 02 — Install dependencies
sudo apt install autoconf automake libtool -y
sudo apt-get install libgflags-dev libsnappy-dev \
  zlib1g-dev libbz2-dev liblz4-dev libzstd-dev -y
git submodule update --init
cd third_party && sh onekey.sh && cd -

# 03 — Build & test
make proto && make -j4
make run
